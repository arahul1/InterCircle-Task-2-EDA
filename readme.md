# Exploratory Data Analysis (EDA) on Titanic Dataset

## Objective
To analyze the Titanic passenger dataset using Pandas, identify missing values and duplicate records, calculate descriptive statistics, and discover survival patterns through grouping and aggregation.

## Key Features
- Dataset loading and inspection using `head()`, `info()`, and `describe()`.
- Missing-value identification and treatment.
- Duplicate-row detection and cleaning.
- Statistical analysis of passenger age, fare, and class.
- Grouping and aggregation using `groupby()`.
- Survival-rate analysis by gender and passenger class.
- Numerical correlation analysis.
- Visualization of survival counts and survival rates.
- Export of the cleaned dataset to CSV.

## Tools Used
Python, Pandas, NumPy, Matplotlib, and Google Colab.

## Expected Outcome
A cleaned and analyzed dataset, descriptive statistical summaries, visual representations of passenger survival patterns, and practical experience with exploratory data analysis.

## Conclusion
This project demonstrates fundamental data science techniques, including dataset inspection, data cleaning, statistical analysis, grouping, and visualization. It establishes a foundation for further work in data visualization and machine learning.
